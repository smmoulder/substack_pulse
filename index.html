Connect your Substack session

Install the included Chrome extension, then visit your Substack publisher dashboard while signed in. Pulse captures only dashboard JSON responses and keeps them in extension storage on this device.

  1. Open chrome://extensions.
  2. Enable Developer mode and choose Load unpacked.
  3. Select this project’s extension folder.
  4. Visit your Substack dashboard, browse its analytics and comments pages, then return here and select Sync now.
No password or session cookie is read, copied, or stored by Pulse.
